# Portfolio Certificate Assets

This directory is reserved for certificate files displayed by the personal portfolio.

## Current status

No certificate documents or image files are currently committed in this directory. Add a certificate only after verifying that it belongs to the portfolio owner and that it is appropriate to publish publicly.

## Suggested organization

When certificates are added, group them by subject area. For example:

```text
public/certificates/
├── ai-ml/
├── web-fullstack/
├── programming/
├── cloud-databases/
└── hackathons-workshops/
```

Supported web-friendly formats include PDF, PNG, JPG/JPEG, WebP and SVG. Use descriptive file names, keep the original certificate legible, and avoid publishing private identifiers, addresses or other sensitive information.

Because this directory is under the frontend's `public/` folder, files added here may be publicly served by the deployed site. Do not store private documents or unredacted personal records here.
